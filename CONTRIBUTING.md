# contributing

спасибо, что дошли до этого файла. проект маленький, правила простые.

## before you start

* проверьте, что `make test` проходит на чистой копии
* для крупных изменений откройте issue с описанием, чтобы не переписывать
  работу дважды

## build and test

    make test
    python3 sysblink.py --list_patches
    python3 -m py_compile sysblink.py preview.py

шлюз жесткий: c99, pedantic, все предупреждения как ошибки. локальная
сборка включает fortify, как на раннере, поэтому игнорировать результат
write или ftruncate нельзя.

## adding a patch

патч это один файл c в patches, определяющий `int get_led_value(void)`.
функция возвращает 0 до 100 и не спит. контракт и разобранный пример
лежат в docs/patches.md и docs/patches.ru.md.

если ваш патч читает новый источник, добавьте фикстуру в tests/fixtures
и точное ожидание в tests/run.sh. проверка на живых данных без фикстуры
не принимается как доказательство.

## style

* комментарии и документация строчными буквами, без длинного тире
* комментарий объясняет почему, а не пересказывает код
* магические числа живут в patches/config.h с единицей в комментарии
* один патч, одна ответственность, без новых библиотек

## commits

один логический шаг, один коммит. сообщение в формате
`type(scope): verb`, типы: feat, fix, test, docs, refactor, sweep, ci.
коммит только после зеленого `make test`.

## license

отправляя изменение, вы соглашаетесь, что оно распространяется под mit,
как и весь проект.
