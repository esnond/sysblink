sysblinkзапасной светодиод превращается в приборную панель

у каждой материнской платы и корпуса есть светодиоды, которые всю жизнь показывают одно и то же. sysblink забирает один из них и учит его полезному: загрузка процессора, память, диск, сеть, температура, что угодно, за чем следит патч.

выбираете диод и метрику, установщик собирает маленький c демон из шаблона и отдаёт его вашему init. после перезагрузки моргалка продолжает моргать осмысленно.

sysblink install --led power --patch cpu
sysblink list
sysblink remove power

написано с помощью ии, честно заявлено в readme. мигает по расписанию, как и всё в этом профиле.
